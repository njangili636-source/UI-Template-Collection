MEMBER-2 PRO FINAL

Four mini applications: WaveBox, FoodFlow, TripNest and CareerHub.

Important:
- Open the root index.html to launch the apps.
- Each app also works when its own index.html is opened directly.
- Shared image assets are copied into each app's assets folder so relative image paths work.
- FoodFlow includes the user-provided Chicken Biryani and Pizza images as local files.
- WaveBox audio demo tracks require internet access.
- CareerHub includes search, filters, details, save/apply actions, favorites and a workspace.
